# Toil Bot

Toil Bot is a vibe-coded productivity app that helps you focus on the task at hand. Add the tasks you are working on using the text box and then cycle through what gets focussed on as progress is made.

The top item should be where your focus lies. As soon as you are waiting on some external input, "Bump" the task to the bottom and focus on the next task.

When a task is complete, hit "Finish".

Re-arrange tasks as needed.
